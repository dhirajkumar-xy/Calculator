
# Calculator - Python CLI App
### Task 1 | Python Developer Internship - Elevate Labs

A simple and interactive command-line calculator built in Python.

#### Objective
Create a command-line calculator supporting basic operations (+, -, *, /).

#### Features
- Addition, Subtraction, Multiplication, Division
- Uses functions for each operation
- Takes user input using input()
- Loop until user chooses to exit
- Handles division by zero error

#### How to Run
python calculator.py
